# quant-cn — A股 + 港股量化虚拟盘交易系统

结合本机 **vibe-trading**（LLM 分析层）与 **akshare**（免费行情数据），实现
**数据 → 策略信号 → 虚拟盘撮合 → 回测 → 日报** 的全自动闭环，聚焦 A股与港股。

## 一、主流量化策略梳理与选型

| 策略类别 | 核心逻辑 | A股/港股适配性 | 本系统 |
|---|---|---|---|
| 趋势跟踪（双均线/突破） | 顺势持有，止损离场 | ✅ 适合日线；T+1 下用"收盘信号、次日成交"规避 | ✅ 子账户1 |
| 均值回归（RSI2/布林回归） | 短期超卖反弹 | ✅ 优质龙头长期漂移向上，胜率高 | ✅ 子账户2 |
| 截面动量（相对强弱轮动） | 做多近期最强的一篮子 | ✅ 经典股票轮动，跨 A/港 统一排名 | ✅ 子账户3 |
| 多因子（价值/质量/低波） | 因子打分选股 | ✅ 但需财务数据，复杂度高 | 🔜 可扩展 |
| 统计套利/配对交易 | 协整价差回归 | ⚠️ A股无法做空，仅港股可行 | 🔜 可扩展 |
| 网格交易 | 区间高抛低吸 | ⚠️ 单边行情风险大 | ❌ |
| 高频/日内 | 微观结构获利 | ❌ T+1 与成本限制 | ❌ |

**组合方式（sleeve 结构）**：趋势 40% + 均值回归 30% + 截面动量 30%。
每个子账户内部对触发标的等权，单票上限 25%，其余留现金。
三类策略相关性低（趋势怕震荡、回归怕单边、动量吃轮动），合成后回撤平滑。

## 二、市场规则建模

- **A股 T+1**：信号收盘计算、当日收盘虚拟成交；每日仅调仓一次，当日买入最早次日之后卖出，天然满足 T+1。
- **手续费**：A股 佣金万2.5(最低5元) + 印花税卖出0.05% + 过户费0.001%；
  港股 佣金0.05%(最低5HKD) + 印花税双边0.1% + 交易/交收费≈0.01%。
- **整手交易**：统一按 100 股一手（简化）。
- **汇率**：中行 HKD/CNY 折算价实时抓取（兜底 0.8566），港股市值折 CNY 统一核算。
- **数据源**：A股 东财→新浪 双源回退（本机东财偶发拒连）；港股 新浪；
  基准 沪深300(sh000300) / 恒生指数(HSI)。

## 三、目录结构

```

├── config.yaml          # 标的池/策略参数/费率/风控

│   ├── portfolio.py     # 组合层：三 sleeve 合成目标权重
│   ├── broker.py        # 撮合层：费率模型 + 整手 + 现金约束
│   ├── backtest.py      # 回测引擎 + 绩效指标 + 图
│   ├── engine.py        # 虚拟盘：状态持久化(paper.json) + 每日调仓
│   └── report.py        # 日报：持仓/成交/全池信号/AI点评/净值图
├── data/                # 行情 CSV 缓存
├── state/paper.json     # 虚拟盘账户状态
├── reports/             # 日报 md + 净值/回测 PNG
└── logs/                # cron 日志
```

## 四、使用

统一用 vibe-trading 的 Python（已含 akshare/pandas/matplotlib）：

```bash
VT=/home/ben/.local/share/pipx/venvs/vibe-trading-ai/bin/python
cd quant-cn
$VT main.py update              # 刷新行情缓存与汇率
$VT main.py backtest            # 回测：组合 + 单策略消融 + 基准对比
$VT main.py trade               # 执行最新交易日虚拟盘调仓（幂等）
$VT main.py report --ai         # 生成日报（--ai 调 vibe-trading 点评）
$VT main.py daily --ai          # 一条龙：update + trade + report
$VT main.py status              # 查看虚拟盘账户
```

**自动化**：已安装 crontab，每个交易日（周一~五）16:20 自动执行
`daily_job.sh`（含 AI 点评），日志在 `logs/cron.log`。任务幂等，
重复运行自动跳过已执行日期；节假日无新数据自然空转。

## 六、vibe-trading 的角色

- **AI 点评层**：日报通过 `vibe-trading run -p` 调用本机 LLM，对当日
  虚拟盘持仓/净值给出风险分析（失败不影响主流程）。
- **可借力的技能**：`akshare`/`data-routing`（数据源决策）、`strategy-generate`
  （生成新策略并回测）、`alpha-zoo`（因子库 IC/IR 检验）、`correlation-analysis`
  （配对交易协整检验，做港股 pairs 时接入）。
- 扩展路径：把 `qts/strategies.py` 新增信号函数 → `portfolio.py` 加 sleeve →
  回测对比 → 调 config 权重，即可上线新子策略。

## 七、已知限制

- 撮合按收盘价，无盘中滑点；港股每手股数简化为 100。
- 未含分红除权现金流（用前复权价近似）。
- 汇率每日一个值，未建模换汇时点差。
- 东财接口偶发拒连已用新浪回退，若双源同挂当日会跳过（cron 日志可见）。
